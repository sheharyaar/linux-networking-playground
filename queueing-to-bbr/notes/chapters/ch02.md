## Errata and since-the-paper notes
Errata (each checked on the rendered page):
- Appenzeller p. 283: the sender "times-out" and then halves; a timeout drops the window to one packet, and the halving comes from fast retransmit. (On the page.)
- Appenzeller p. 286 table: 1.5·BDP/√n listed as "Util ≥ 99.99988%"; Eq. 3 gives erf(2.715) = 99.988%. (On the page.)
- B&G solutions manual, Problem 3.4: prints λ* = 1/√(αβ); the correct value is 1/(2√(αβ)). (In the bookq answer.)
- B&G Problem 3.9 (p. 243): printed N_Q = 5, N = 10 for the split line are totals over ten sessions, though the stem says "for each session". (In the bookq answer.)
Since the paper:
- CUBIC is Linux's default (RFC 9438, 2023, "Fairness to Reno": AVG_W = 1.054(RTT/p)^¾); the Reno-friendly region is on by default (`tcp_cubic.c:53`, tcp_friendliness = 1).
- Linux Reno grows by acked segments (`tcp_cong_avoid_ai()`, `tcp_cong.c:470`), so delayed acks no longer lower C to 0.87.
- Redux 2019 (CCR 49(5) p. 71): Level 3 link cut from 190 ms to 1 ms of buffer with no measurable throughput loss; Internet2 link with 150 flows needed 26 kB against 648 kB.
