## ch12 additions (verified 2026-09-18)
ip-link(8) https://man7.org/linux/man-pages/man8/ip-link.8.html "ip-link(8) — Linux manual page" — documents the macvlan modes in full (private, vepa, bridge, passthru, source); mentions ipvlan only as "Interface for L3 (IPv6/IPv4) based VLANs" and does NOT list l2/l3/l3s, so cite ipvlan.html for those.
docs.kernel.org/networking/ipvlan.html "IPVLAN Driver HOWTO" — documents l2/l3/l3s and the three reasons to prefer ipvlan (switch permits one MAC per port; too many MACs degrades the switch; untrusted namespaces where L2 manipulation is a risk).
https://docs.docker.com/engine/network/drivers/macvlan/ "Macvlan network driver" — parent interface requirement; states the network equipment "needs to be able to handle 'promiscuous mode', where one physical interface can be assigned multiple MAC addresses"; notes most cloud providers block macvlan. Does not discuss wireless.
